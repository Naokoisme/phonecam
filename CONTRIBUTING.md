# Contributing to PhoneCam / 参与 PhoneCam

Thank you for helping improve PhoneCam. Compatibility reports, reproducible bug reports, documentation fixes, translations, and focused code contributions are all useful.

感谢你帮助改进 PhoneCam。兼容性测试、可复现的缺陷报告、文档修正、翻译和范围明确的代码贡献都很有价值。

## Report a bug / 报告问题

Use the repository's bug-report form and include:

- Phone model and Android version
- Windows version
- USB or Wi-Fi connection
- Video application and version, if relevant
- Exact steps to reproduce the problem
- Expected and actual behavior
- Logs or screenshots you choose to share

请使用仓库的缺陷报告表单，并提供手机型号、Android 与 Windows 版本、连接方式、复现步骤、预期结果和实际结果。

Before publishing logs or screenshots, remove account names, IP addresses, device identifiers, and any other information you consider private.

发布日志或截图前，请删除账号名、IP 地址、设备标识符及其他你认为敏感的信息。

## Request a feature / 提出功能建议

Describe the user problem first, then explain the proposed behavior. Include alternatives or workarounds you have tried. A clear use case is more useful than a feature name alone.

请先描述实际使用问题，再说明希望出现的行为，并补充尝试过的替代方案。清晰的使用场景比单独的功能名称更有帮助。

## Submit code or documentation / 提交代码或文档

1. For a substantial change, open an issue before implementation so the scope can be discussed.
2. Keep each pull request focused on one problem.
3. Follow the [development guide](docs/development.md) for build and release requirements.
4. Update documentation when behavior changes.
5. Do not describe untested compatibility as verified support.

较大的修改请先创建 Issue 讨论范围；每个 Pull Request 只解决一个明确问题，并确保文档、实现和已验证能力保持一致。
