Turn an Android phone into a Windows webcam over USB or Wi-Fi.

## Download PhoneCam v2.0.3

| Install on | Download |
|---|---|
| Windows 10/11 PC (x64) | [Download the Windows installer](https://github.com/Naokoisme/phonecam/releases/download/v2.0.3/PhoneCam-Windows-v2.0.3.exe) |
| Android 7.0 or later | [Download the Android APK](https://github.com/Naokoisme/phonecam/releases/download/v2.0.3/PhoneCam-Android-v2.0.3.apk) |

The Windows and Android apps work together. The Windows installer includes a tool that can install the companion Android app, so you do not need to download the APK separately if you use that setup flow.

## What changed

- **Fixed failures when downloading USB connection components.** The setup tool now provides clearer recovery guidance when a download fails.
- **Added Android app installation and repair.** Open **PhoneCam USB and Android Setup** from the Windows Start menu to install the companion app or resolve conflicts with older test builds.

## Before you start

- USB mode requires Android USB debugging and approval of the connected computer.
- Read the warning before allowing the repair tool to remove an older Android build. **Removing it deletes that app's data.**
- PhoneCam currently transmits video only. Use the PC's built-in microphone or an external microphone for audio.
