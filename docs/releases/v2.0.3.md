把 Android 手机变成 Windows 电脑的摄像头，支持 USB 和 Wi-Fi 连接。

## 下载 v2.0.3

| 安装到哪里 | 下载 |
|---|---|
| Windows 电脑（10/11，x64） | [下载电脑端](https://github.com/Naokoisme/phonecam/releases/download/v2.0.3/PhoneCam-Windows-v2.0.3.exe) |
| Android 手机（7.0 及以上） | [下载手机端](https://github.com/Naokoisme/phonecam/releases/download/v2.0.3/PhoneCam-Android-v2.0.3.apk) |

两端配套使用。电脑安装包带有手机端安装工具；如果已通过向导装好手机端，无需重复下载 APK。

## 这次更新了什么

- **修复 USB 连接组件下载失败。** 下载遇到问题时，会给出更清楚的处理提示。
- **新增手机端安装与修复。** 从 Windows 开始菜单打开“PhoneCam USB 与手机端设置”，即可安装配套手机 App，或处理旧版本安装冲突。

## 开始使用前

- USB 连接需要开启手机“USB 调试”，并在手机上允许电脑连接。
- 修复向导若提示卸载旧版，请先阅读提示；**确认卸载会删除旧应用数据**。
- 当前仅传输视频，声音请使用电脑内置或外接麦克风。
